## Findings

### Bug fixed mid-smoke — v0.0.3
- **Symptom**: `/api/entities` → 500 `AttributeError: 'list' object has no attribute 'get'`
- **Root cause**: HA WS API `config/entity_registry/list` returns a list, not `{"entities": [...]}`. Backend assumed dict.
- **Fix**:
  - `routers/entities.py`: accept both shapes (list or `{entities:[...]}` wrapper).
  - `adapters/ha_client.py`: `send()` return type widened to `Any`; reader no longer mangles empty lists to dicts via `or {}`.
  - `tests/conftest.py` + `tests/test_routers_entities.py`: mock now returns list (matches real HA shape).
- **Result**: 27/27 tests green, endpoint 200 in production.

### Smoke procedure deviations
- Step 6 path in original procedure was `/ws/state-stream`. Verified correct (no `/api` prefix on the WS router).
- HA Ingress requires session cookie auth — `Authorization: Bearer` is rejected. Curl smoke executed via browser DevTools (`fetch` with `credentials:'include'`) on the Ingress-Web-UI tab instead of bare curl.
